Recommended sizes / formats
- Landscape 4:3, any image format / size (resized to 700 / 1400 px WebP + AVIF at build).
- Keep each source under ~3 MB (originals are deployed too).

Rules (all media): real photography only. No AI-generated images, no stock illustrations.
Record every third-party file in docs/CREDITS.md and tick it off in docs/PLACEHOLDERS.md.
