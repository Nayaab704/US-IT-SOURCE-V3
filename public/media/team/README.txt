Team portraits

What goes here
- firstname-lastname.jpg : REAL portraits of US IT Source people, with their consent.
  Never stock photos or generated faces.

Recommended sizes / formats
- 1200x1500 (4:5). Same light / background for all.
Any format / size: PNG, JPG, WebP or AVIF (a wrong extension is fine too). The build reads each file,
resizes it and converts it to WebP (+ AVIF for photos) with a content hash in the name, so a replaced
file always shows up. Your originals are never changed — but they are deployed too, so keep each
source under about 3 MB (around 3000 px is plenty).

Rules (all media): real photography / real screens only. No AI-generated images, no stock
illustrations, no icons as decoration. Keep sources under ~3 MB. Record every third-party file in
docs/CREDITS.md and tick it off in docs/PLACEHOLDERS.md.
