Project: Material Nesting Software (Nester)

What goes here
- 01.png, 02.png ... : real screens of the delivered software, in the order to show them; NN-mobile.*
  (or any portrait image) is shown in a phone frame. REDACTED or DEMO DATA only (no client names,
  prices, people or plates unless the client approved it) — or list the areas to hide in
  public/media/redactions.json (blocked in the published copy only).
- environment.jpg : a photograph of the place the software runs in (the cutting shop: sheet stock, CNC / plasma / laser table, cut parts).
- loop.mp4 + loop.webm (optional): a short muted screen recording, seamless loop.

Recommended sizes / formats
- Screens: capture at 2880x1800 (16:10, retina) or phone 1170x2532.
Any format / size: PNG, JPG, WebP or AVIF (a wrong extension is fine too). The build reads each file,
resizes it and converts it to WebP (+ AVIF for photos) with a content hash in the name, so a replaced
file always shows up. Your originals are never changed — but they are deployed too, so keep each
source under about 3 MB (around 3000 px is plenty).
- Environment photo: 2560x1440 (16:9) JPEG quality ~80, <= 450 KB.
- Loop video: 1920 px wide, 6-12 s, H.264 MP4 + VP9 WebM, muted, <= 4 MB each, plus a
  poster JPEG of the first frame.

Rules (all media): real photography / real screens only. No AI-generated images, no stock
illustrations, no icons as decoration. Keep sources under ~3 MB. Record every third-party file in
docs/CREDITS.md and tick it off in docs/PLACEHOLDERS.md.
